# kayode_toluwani_joseph_workshop_energy_cost_estimator
This is my written program that gets information from a User about the Tools used in an Engineering Workshop and additional details like Power Rating in Watts and Time in Minutes to be able to calculate Energy used and also Cost based on our local tariff in Nigeria. It also estimates Monthly Energy and Cost too

Project Title: WORKSHOP ENERGY COST SIMULATOR

What it does:
A Python-based automation tool designed for workshop owners to accurately calculate, track, and analyze daily and monthly energy consumption (kWh) and electricity costs.

How to run it:
Install Python 3, Visual Studio Code, And Also Install A Python Extension On Visual Studio Code, then run: python project.py
